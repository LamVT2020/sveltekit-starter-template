# AI Prompts & Engineering Playbooks

This directory houses operational and generative prompt templates used by engineering teams and AI coding assistants to design, build, test, and harden features across the application.

## Directory Layout
- `AI_FEATURE_BUILDER_PROMPTS.md`: Step-by-step prompts for building domain modules, APIs, and UI components following our canonical architecture.
- `PROJECT_HARDENING_PROMPTS.md`: Prompts for security scanning, dependency auditing, rate limiting, and environment variable validation.
- `TASK_QUALITY_ASSURANCE_PROMPTS.md`: Prompts for generating Vitest unit tests, Playwright E2E suites, and coverage verification.
